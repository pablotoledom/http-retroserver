# retroserver

> [Versión en Español](LEAME.md)

A lightweight HTTP/HTTPS static file server written in C. Designed for retro compatibility — the directory listing works on browsers as old as Internet Explorer 3.0 and Lynx with a phosphor green terminal aesthetic.

---

## Features

- Serves static files with an auto-generated directory listing
- Optional HTTPS via OpenSSL (TLS)
- Force-download any file with the `?dl` query parameter
- MIME type detection for common file formats
- Multi-threaded connection handling
- Path traversal protection (blocks `..` and symlink escapes)
- Configurable via a plain text config file
- Graceful shutdown on `SIGINT` / `SIGTERM`
- Installable as a systemd service
- **Retro compatible:** directory listing tested down to IE 3.0
- **Phosphor green UI:** black background, green terminal style
- **Self-contained binary:** icons and HTML templates are embedded at compile time — no extra files needed at runtime

## Requirements

- GCC or Clang
- CMake 3.10+
- OpenSSL (`libssl-dev`)

```bash
# Debian / Ubuntu
sudo apt install build-essential cmake libssl-dev
```

## Build

```bash
# Production build
./retroserver.sh compile

# Debug build (with debug symbols)
./retroserver.sh compiledebug
```

The binary is placed in `bin/retroserver` along with `configs/` and `ssl/`. Icons and HTML templates are compiled directly into the binary — no additional folders are needed at runtime.

## Usage

```bash
./retroserver.sh run [directory]
```

If no directory is specified, the current directory is served.

**Examples:**

```bash
# Serve the current directory
./retroserver.sh run

# Serve a specific directory
./retroserver.sh run /home/user/files
```

Once running, open your browser at:

- HTTP:  `http://localhost:8080`
- HTTPS: `https://localhost:8443` (when SSL is enabled)

## Configuration

Edit `configs/config.txt`:

```ini
# Log level: 0=none 1=error 2=warn 3=info 4=debug
verbose_level=3

# HTTP port
http_port=8080

# HTTPS (optional)
https_port=8443
ssl_enabled=0
ssl_cert=./ssl/cert.pem
ssl_key=./ssl/key.pem
```

Set `ssl_enabled=1` to enable HTTPS.

## SSL / HTTPS

**Generate a self-signed certificate:**

```bash
./retroserver.sh cert
```

This creates `ssl/cert.pem` and `ssl/key.pem`. Then enable SSL in the config:

```ini
ssl_enabled=1
```

> **Note:** Self-signed certificates will show a browser security warning. You can accept it manually or add the certificate to your system's trusted store.

## Customizing the UI

### HTML Templates

The page structure lives in `html/`. Edit these files and recompile to apply changes:

| File | Description | Variables |
|------|-------------|-----------|
| `html/dir_header.html` | Page header and listing opening | `{{PATH}}` |
| `html/dir_footer.html` | Page footer | *(none)* |
| `html/error.html` | Error page | `{{CODE}}`, `{{STATUS}}` |

At compile time, these files are embedded into the binary automatically. No separate deployment needed.

### Icons

Icons are 16×16 GIF images in `icons/`, generated by `scripts/gen_icons.py`. To customize:

1. Edit `scripts/gen_icons.py` (or replace any `.gif` in `icons/` with your own)
2. Recompile — CMake detects the change and re-embeds the icons

| Icon | File types |
|------|------------|
| Folder | Directories |
| Sound | mp3, ogg, wav, flac, aac, m4a, wma |
| Video | mp4, mkv, avi, mov, webm, flv, wmv |
| Image | jpg, jpeg, png, gif, svg, webp, ico, bmp |
| Archive | zip, gz, tar, 7z, rar, bz2, xz |
| PDF | pdf |
| Disc | iso, cue |
| Executable | exe, bin |
| Text | txt, md, log, csv, rtf |
| Source | c, h, cpp, py, sh, js, json, html, xml, go, rs, yaml |
| File | Everything else |

## Systemd Service

```bash
# Install as a service
sudo ./retroserver.sh install

# Remove the service
sudo ./retroserver.sh uninstall
```

## Available Commands

| Command        | Description                            |
|----------------|----------------------------------------|
| `compile`      | Build for production (Release)         |
| `compiledebug` | Build with debug symbols               |
| `run [dir]`    | Run the server (default: `.`)          |
| `cert`         | Generate a self-signed SSL certificate |
| `install`      | Install as a systemd service           |
| `uninstall`    | Remove the systemd service             |

## Project Structure

```
retroserver/
├── src/
│   ├── main.c
│   ├── server/
│   │   ├── start_stop.c          # Server lifecycle
│   │   ├── connection.c          # Socket abstraction (plain + TLS)
│   │   ├── connection_thread.c   # Thread-per-connection handler
│   │   ├── http_request_parser.c
│   │   ├── request_handler.c     # Routes requests
│   │   ├── static_handler.c      # File serving and directory listing
│   │   ├── icons_handler.c       # Serves embedded icons at /_icons/
│   │   └── ssl_manager.c         # OpenSSL context setup
│   └── utils/
│       ├── config_loader.c
│       ├── server_utils.c        # MIME types, URL encode/decode, template engine
│       └── log.h
├── html/                         # HTML templates (embedded at compile time)
│   ├── dir_header.html
│   ├── dir_footer.html
│   └── error.html
├── icons/                        # GIF icons (embedded at compile time)
├── configs/
│   └── config.txt
├── ssl/                          # Certificate files (generated)
├── scripts/
│   ├── gen_icons.py              # Regenerate icons (requires Pillow)
│   ├── gen_icons_c.sh            # Embeds icons into C source (run by CMake)
│   ├── gen_html_c.sh             # Embeds HTML into C source (run by CMake)
│   └── ...
└── retroserver.sh                # Main entry point
```
